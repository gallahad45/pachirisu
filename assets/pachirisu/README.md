# Pachirisu images

One image per mood, transparent PNG, any size (shown about 170 px tall).

| File | When |
|---|---|
| `idle.png` | the rest of the time |
| `happy.png` | you just KO'd a Pokémon (3.5 s) |
| `sad.png` | one of your Pokémon just fainted (3.5 s) |
| `win.png` | you won |
| `lose.png` | you lost (or tied) |

A missing file falls back to `idle.png`. After changing an image, reload the
extension in `chrome://extensions`, then reload the Showdown tab.
